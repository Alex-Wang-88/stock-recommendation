# 每日五选 v2：冻结规则与前向验收

主产品是 `site/index.html`，由 `scripts/daily_picks.py` 更新并构建到 `_site/`。
核心链路仅使用 Python、Pandas、DuckDB、Requests 和静态 HTML/CSS/JavaScript。
不调用语言模型，不依赖 Streamlit、财务同步、公告分类或题材接口。原研究代码保留以便追溯。

## 策略

规则在第一次观察新方案的历史/未来收益之前写入 `config/daily_strategy.json`。
中期趋势40%、低波动40%、5日回撤20%，在同一个完整候选池中按分位加权。
趋势取20日前到120日前的收益，低波动取60日日收益总体标准差的反向分位。
行业最多一只；行业缺失共享一个桶。行业快照只作集中度控制，不作历史时点分类证明。

股票池限定沪深主板：同日名称非ST/退市、上市满365天、250根有效日线、价格至少3元、
20日平均成交额至少1亿元、中期趋势为正、价格高于120日均线。
全体满足基础数据/名称条件的样本中，高于120日均线比例低于40%时，本期空仓。
最多5只，数量不足不放宽条件。权重没有经过收益优化，不宣称已经取得超额。

候选每天独立记录，不等于把5只股票每天全部买入一个真实持仓账户。
如果未来需要一个连续账户，应先另行冻结仓位预算、调仓和退出协议。

## 执行和比较

每个信号对应一个独立10万元模拟批次，次日真实开盘尝试买入，100股整手；
每侧成本20bps、每笔至少5元。该费用是统一成本情景，不是完整券商税费清单。
开盘达到前收盘的109.5%、停牌、买入日ST或预算不足一手时不买，分配保留现金。
从入场日起计20个交易日；无法交易或收盘不高于昨收的90.5%时延迟退出。
这是保守日线撮合，不声称能够模拟盘中排队或大单冲击。

信号使用前复权日线；执行只用信号之后每日真实留存的未复权开/收盘快照。
买入证据必须在该日收盘后、下一工作日开盘前抓取，迟到的数据不得补造前向成交。
持有期间昨收与上日收盘偏差超过0.5%时标为公司行动待核对，不自行猜测拆股或分红。
现金分红暂未入账，所以结果是价格收益。异常样本始终显示并阻止观察门槛达标。

主基准在观察收益前固定为中证全指价格指数000985，使用中证官网真实开盘/收盘。
策略全部退出日与指数终点对齐；缺少基准时超额保持空值。
同池等权对照使用固定信号日股票池和相同费率，但采用分数单位、不含最低费用和整手，
因此明确标为近似对照。两项超额都保留，不按结果改选基准。

60个成熟批次、平均指数超额>0、平均同池超额>0，且没有缺失/退出受限样本，
才显示达到观察门槛。该门槛不是统计显著性或盈利保证。每天的20日批次重叠，
不把批次均值拼接、复利或年化；空仓日也留证并与同期指数比较。

## 留证与恢复

`data/reports/daily-v2/` 包含：

- `signals/`：信号、时间、完整股票池、规则快照和SHA-256，首次创建后不覆盖。
- `quotes/`：逐日原始报价证据；首次完整快照固定，显式零成交与下载失败分开处理。
- `entries/`：按冻结信号生成的买入数量/费用/现金账本，含完整性校验。
- `benchmark.json`：官方中证全指记录、来源、参数及原响应哈希。
- `evaluation.json`：包括待完成、受限和缺失批次的全部验证结果。
- `latest.json`：当前产品快照，历史数据不会显示为当天推荐。

更新使用跨进程文件锁，网络最多6 workers，Windows BelowNormal，BLAS单线程。
DuckDB写入后消费COPY结果再注销视图；生产依赖由 `runtime-constraints.txt` 固定。
GitHub Actions在北京时间工作日17:17执行，恢复上一完整状态、同步、保存快照、部署。
上游失败仍发布带日期的历史页面，并将工作流标为失败；不会用零值伪造超额。

首次新版留证来自实际运行当时的行情，不把旧推荐重新算成新版历史成绩。
任何权重/门槛修改都必须使用新版本；同一个版本出现不同规则哈希会拒绝继续留证。

## 运行

```powershell
.\.venv\Scripts\python.exe scripts/daily_picks.py --workers 6
.\.venv\Scripts\python.exe scripts/serve_daily.py
```

`--saved-only` 仅重建，不联网、不新增留证。已抓齐且仍在前向时限内的数据可显式加
`--freeze-saved` 留证；该选项仍不能回填已经过去的推荐。
本地网页为 `http://127.0.0.1:8501/`，只暴露生成的公共目录。公共网页继续使用原GitHub Pages地址。
