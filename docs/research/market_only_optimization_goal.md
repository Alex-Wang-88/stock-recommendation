# 价量策略首轮优化目标

2026-10-14冻结。目标尚未达成，属于研究验收标准，不是收益预测。

基线采用较宽候选池、类别等权、连续持仓差额调仓、单边10bps。现有14段均为已经查看的30交易日窗口。

| 指标 | 基线 | 首轮目标 |
| --- | --- | --- |
| 中证全指价格指数平均净超额 | −0.29个百分点 | ≥+0.50个百分点 |
| 同池等权平均净超额 | 约0个百分点 | ≥+0.30个百分点 |
| 同14段平均净收益 | 4.08% | ≥4.86%，由相同指数平均收益加0.50个百分点推导 |
| 跑赢中证全指的区间 | 7/14 | ≥9/14 |
| 最差区间净收益 | −20.27% | ≥−15% |
| 各区间最大回撤中的最差值 | −21.49% | ≥−15% |
| 单边20bps压力测试的平均全指超额 | −1.31个百分点 | ≥0 |
| 对齐首日收盘至末日收盘的全收益指数超额 | −0.24个百分点 | ≥0 |

上述首轮门槛同时满足才标为研究目标通过。进阶目标是平均全指超额达到+1.0个百分点，风险和验证门槛保持一致。4.86%只对应相同14段的市场涨跌，不能当作未来每30日的固定收益目标，更不能复利成年化预测。

净收益改善0.5—1.0个百分点可以作为首轮争取范围，但目前没有证据给出实际改善的可靠预测。依据是原方案零费用平均收益5.11%，10bps后4.08%，两者相差1.03个百分点。该差值是保持原持仓与规则、费用降至零的理论空间；实际交易不可能把费用完全归零，改变调仓也会改变收益。

因此，降低换手只能解决部分问题。原方案零费用同池超额也仅约+0.16个百分点，达到+0.30个百分点的同池目标还需要排序、入池或持仓结构本身改善。先诊断7项价量因子，再独立测试降低换手、股票池门槛和风险配置；记录全部尝试，冻结少量候选后比较，不按结果不断追加参数。

指数继续用完整窗口买入持有。若引入仓位或择时规则，原全仓对照继续保留，同时增加应用相同仓位规则的同池对照，避免把市场敞口变化全部解释成选股能力。停牌、跌停无法退出时继续计入持仓净值，15%风险门槛只是回测验收标准。

这14段只用于开发研究。候选冻结后，在未查看的连续时间序列或前向模拟上使用相同指标验证；至少6段互不重叠的30交易日窗口作为初步验收，平均全指超额≥+0.5个百分点、同池超额≥+0.3个百分点、胜率≥60%、损失和回撤门槛及费用压力门槛保持一致。未来绝对收益随市场变化，不要求每段赚4.86%。初步验收后仍需更长观察及复权、退市和历史股票全集审计，才能讨论生产替换。

若目标未达成，明确记录失败，不在看过结果后下调门槛或把旧窗口重新标为样本外。[CFA回测方法](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/backtesting-and-simulation)也强调滚动验证、压力情景以及前视和幸存者偏差。
