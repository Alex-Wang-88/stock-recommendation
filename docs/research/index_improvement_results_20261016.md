# 以跑赢指数为目标的结构优化（2026-10-16）

**本轮未达到稳定跑赢指数的目标。**六段新历史中，沪深300候选平均指数超额-0.36个百分点，跑赢3/6段；中证500候选平均超额-1.93个百分点，跑赢0/6段。旧样本中的改善不能据此视为可迁移的收益。

本轮固定18个方案，在两个历史成分股池、15个已查看的30交易日区间中进行开发对照。复用已冻结的P4/Lasso/LightGBM评分，检验放量门槛、调仓周期及持仓分散度，未重新搜索模型参数。

随后每个股票池只封存一个候选，验证6个此前未查看的历史区间，再检查冻结数据之后的9个交易日。历史验证时间早于开发样本，属于反向时间的历史压力检验；不能替代未来模拟跟踪。

本轮开发区没有方案全部通过8项冻结门槛，因此两个候选均为研究候选，未替换生产默认评分。以下30日收益为独立窗口的算术均值，不拼接、复利或年化；主费用为买卖各0.1%，超额为百分点。

## 实现和边界

- 开发区实际回放1,620个策略账户及360个独立同池对照；表内重复展示的同池对照不重复计为计算账户。原规则复现最大收益差约为9.9e-17。
- 从逐笔交易独立重算现金和数量后，每日净值最大差为1.14e-14；手续费账本、费用敏感性、训练标签边界及封存哈希检查通过。新报价中昨收与上一有效收盘偏差超过10bps的记录共12条，逐项保存在各验证目录的`quote_prior_close_gaps.csv`。这些记录不在账户评估日内，但可能进入回看特征和训练数据；特殊公司行动和复权连续性尚未逐项修复核验。
- 验证报价来自BaoStock前复权日线；历史成分股按日期查询，含当时存在、现在可能已退出的股票。下载无报价任务数为0；完整逐项下载状态保存在回执中。数据商每周成分更新、少量499只记录及复权版本仍限制精度，不使用最新名单补历史。
- 验证使用各窗口之前的数据重新拟合相同模型参数；训练/验证/测试边界清除尚未完整实现的标签。财报、行业、市值数据仍未进入选股。特征缺失处理仅从训练期拟合。
- 创业板2020-08-24之前按10%规则，之后按20%规则；科创板采用20%。另修正验证引擎将创业板/科创板ST卖出误按5%限制处理的问题，买入仍排除ST。近期验证按2026-07-06起主板ST涨跌幅10%的新规则处理。验证按完整30开头代码范围识别创业板，包括302132。开发旧引擎及旧结果保留，验证候选与对照共同使用修正后的执行逻辑。
- 使用分数股，没有整手、最低佣金、盘中盘口与冲击模型；单边10/20bps是统一费用场景。全收益指数仅有收盘数据，双方采用第一日收盘至末日收盘对齐，不能与开盘主口径互换。
- 六段历史结果是以前未看过的压力检验；其日期早于用于设计方案的2024—2026数据，仍有反向时间选择风险。近期9日区间虽晚于冻结快照，也属于事后历史模拟，不是已运行的实时模拟账户。
- 本轮尚未满足全部开发门槛，目标不得标为已经完成；研究候选单独保存，生产配置保持不变。

## 下一步研究方向

当前证据支持先检查评分的选股增益与收益来源：沪深300候选在开发和新历史中均落后同池等权，中证500的放量门槛改善未迁移到新历史。后续应以指数增强为框架，明确主动偏离和换手预算，检验评分是否能在同池对照上增加收益。这是待验证的研究方向，不是已经证明有效的新方案。

现有15+6段数据现在都已看过，只能继续用于开发和压力检验。下一轮应先冻结评分、执行约束与验收口径，再进行时间顺序向前的验证；不能通过在这21段上反复选择赢家来宣称已经解决超额问题。
