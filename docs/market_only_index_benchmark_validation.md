# 四个指数对照：14段历史区间、8组冻结价量权重

已实际重跑全部 1,344 个策略账户和 196 个原有对照账户，共 1,540 个账户。四个价格指数及对应全收益指数均来自中证官网发布的历史指数值，8条序列各641日，全部覆盖所需420个交易日。重跑的账户收益、逐日净值、持仓和目标名单与原结果完全一致。

本页主表采用连续持仓、差额调仓、单边10bps费用；每个数字是各段独立区间的算术均值，超额单位为百分点。没有把不连续区间拼接成年化收益。0/10/20bps、两种执行、两种股票池、8组权重、全部分段结果都保存在CSV。

中证全指是事先固定的宽市场主参考，其他三条用于观察市值风格；四条都报告，不按跑完后的结果挑选基准。原有同池等权、相同费用和执行的对照继续保留。

## 对齐与费用口径

- **价格指数，30交易日**：首日真实开盘至末日收盘；策略为原30日净账户收益。指数全程买入持有、包含周期之间的隔夜行情，指数不扣交易费用且不包含现金分红。
- **全收益指数，29个收盘间隔**：中证官网只有全收益收盘数据。指数按首日收盘至末日收盘计算，策略也用末日收盘净值/首日收盘净值−1。指数包含税前股息再投资；策略首日收盘以前的入场费用与第一日行情不在该比较期间，之后的费用仍包含。没有用价格指数或估算值伪造全收益开盘。
- 策略净收益对指数毛收益，对指数是较严格的费用口径。官方全收益“税前股息再投资”与费用档位并不是同一个概念。
- “同池超额”也按对应比较期间计算；CSV同时保留原30日同池超额，字段名明确区分。
- 超额为收益率之差，另存相对财富收益；这不是剔除市值、行业等风险暴露后的回归alpha。

## 结果判断

全部14段、连续持仓、单边10bps下，两类股票池的8组权重对中证全指的平均超额均为负；改用对齐收盘期间的全收益指数后，这个结论也成立。此前两项候选虽然对沪深300的平均价格指数超额为正，但对中证500和中证1000仍为负，说明只看沪深300容易高估优势。

原低位池仅风控的后续8段平均价格全指超额为+1.30个百分点，但同池超额为−2.14个百分点；较宽池类别等权的后续8段分别为−0.05和−0.73个百分点。市场对照与同池对照共同看，仍没有充分证据支持把当前候选当作稳定的生产权重升级。

## 研究范围与局限

股票侧继续只使用冻结价量因子、上市日期、历史ST/交易状态及原行情快照；不可复现财报和行业因子未加入评分。当前研究是8组价量权重的受限模型，并不等同线上包含财报和行业因子的完整版。原行情为调整后OHLC，调整算法、退市覆盖及历史股票全集尚未完成独立点时审计，指标不能解释为可实盘保证的收益。

中证全指目前包含北交所，而股票回放池只含沪深；官方指数按编制权重，同池参考等权，二者测量不同问题。实际指数复制或ETF会产生跟踪误差和费用，当前没有把ETF收益混入指数收益。

通过新增指数能够观察市场和市值风格暴露，但不能消除先前查看数据、权重选择或样本不足的影响。后续8段的同池超额仍需单独看，不因全14段平均跑赢某个指数就视为稳定选股能力。生产权重和GitHub网页未修改。
